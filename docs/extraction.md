# 提炼来源与取舍

本包源自一个实际项目中的三角色工作流与分片任务库。提炼依据是当前工作树，不宣称某个已提交版本或 GitHub 发布版本。

| 来源类别 | 提炼内容 | 处理 |
| --- | --- | --- |
| 用户提供的 architect 技能及 references | 假设审计、边界、任务关系与最小拆分 | 保留；任务示例改为分片映射与外部 evidence |
| 用户提供的 verification-owner 技能及 references | oracle-first、风险/层级、冻结与可适配内容 | 保留；旧单体路径改为活动卡路径 |
| 用户提供的 coding-owner 技能及 references | 领取、开发者测试、验证执行、自修复、详细 UAT | 保留；证据示例改为独立文件 |
| 项目 .tasks/WORKFLOW.md | 权威来源、readiness、状态、证据、归档 | 去业务名、固定切换日期、仓库名和历史切换例外 |
| 项目 .tasks/tools 与工具测试 | 定位、校验、上下文、归档 | 只提炼当前 taskctl；测试以新分片库重新构造，不依赖旧清单迁移 |
| 项目入口与 docs 导航/进度约定 | 薄入口、条件加载、工作包阶段记录 | 重新编写通用模板，不复制真实历史 |
| 历史设计、旧清单、旧记录与迁移工具 | 仅用于辨识已被替代内容 | 不作为发布规范来源，不复制进交付包 |

未打包业务源码、实际架构内容、真实任务、验收记录、原始日志、内部配置、账号、本机用户路径及第三方插件技能。技能参考资料是本包自包含的一部分，不依赖来源机器。

`source-manifest.json` 只保存来源类别和提炼时原文件 SHA-256，不含本机路径；用于说明来源快照，不是发布制品签名。MIT 由此次用户明确选择。实际发布者应确认这些来源文件的发布权属；本项目没有从第三方开源仓库推断或更改许可证。

选择文档与轻量工具包，而非完整任务平台：可移植、技术栈无关、无服务器依赖。约束是状态流转、所有权协调、真实证据和验收仍由使用者负责，工具并未实现完整流程自动化。

## 排除复核

不包含旧单体 tasks.yaml、旧双角色方案、PASS → DONE 规则、固定日期切换例外、迁移脚本、来源项目真实任务与归档。`migration` 测试层级仍保留，指目标项目的数据迁移测试，并非旧工作流方案。示例的归档由本次新建虚构数据生成。
