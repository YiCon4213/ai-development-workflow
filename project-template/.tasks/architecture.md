# 当前工作包架构边界

复制后由 Architect 填写；尚无批准工作包。

## Goal
记录问题、参与者和可观察成功结果。
## Assumption Decisions
区分 fact / goal / constraint / proposal / assumption，记录证据、挑战与决策。
## Context
只引用影响当前决策的公开契约及现状。
## Global Constraints
记录授权、安全、兼容、数据和运行限制。
## Forbidden
记录不得用于绕过目标的捷径。
## Global Acceptance Intent
记录工作包整体的可观察结果；任务级使用稳定 AC ID。
## Key Risks
记录重要风险、缓解策略和负责人。
## Architecture Escalation Conditions
记录需要重新决策的契约、边界和范围变化。
